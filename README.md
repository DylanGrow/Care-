# CareCompass Lite 🚑

A privacy-focused, mobile-first PWA for eldercare safety and fall detection.

## ✨ Core Features
* **Fall Detection:** Uses device motion sensors to detect and alert on falls.
* **Voice Reporting:** Hands-free incident logging via Web Speech API.
* **Privacy First:** All data is stored locally via IndexedDB. No servers.
* **Panic Button:** "Hold-to-confirm" SOS button for emergencies.

## 🚀 Quick Start
1. `npm install`
2. `npm run dev` (Development)
3. `npm run build` (Production/GitHub Pages)

## 📱 Mobile Setup
Install by selecting **"Add to Home Screen"** (iOS/Safari) or **"Install App"** (Android/Chrome) to enable offline PWA features.
